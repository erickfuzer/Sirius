A **Sirius 0.2.0** traz o histórico de commits para dentro da IDE. Ela também deixa de usar o nome "Alpha": a partir de agora, recurso novo sobe o segundo número, como `0.3.0`, e só correção sobe o terceiro, como `0.2.1`.

**Ainda em desenvolvimento:** funciona no dia a dia, mas espere arestas. Faça commit do seu trabalho e relate o que encontrar em [Issues](https://github.com/erickfuzer/Sirius/issues).

## Destaques

- **Histórico de commits:** o painel de Git ganhou as abas Mudanças e Histórico. A lista mostra assunto, autor, data e código, e se atualiza quando sai um commit novo.
- **O que mudou em cada commit:** clique em um commit para ver os arquivos dele e em um arquivo para comparar com a versão anterior, lado a lado. Arquivo renomeado mostra o nome antigo e o novo.
- **Mensagem completa:** pare o mouse em um commit para ler a mensagem inteira, com data e hora. O botão direito copia o código do commit.
- **Ícones no centro:** os ícones do terminal, do modo foco, de minimizar, de fechar a janela, de novo arquivo, de nova pasta e de descartar mudanças agora ficam no meio do destaque.

O histórico só lê o repositório. Ele não muda nada, e por enquanto também não volta para um commit antigo.

## Instalação

Baixe `Sirius-0.2.0-Setup.exe` abaixo e abra. Se já tem a Sirius, instale por cima: suas preferências continuam. Ele instala só para o seu usuário, sem pedir administrador, e já leva o .NET junto.

O instalador ainda não tem assinatura digital, então o Windows pode mostrar um aviso azul. Clique em **Mais informações** e depois em **Executar assim mesmo**.

Requer Windows 10 versão 1809 ou mais recente, em 64 bits.

## Limites conhecidos

- O "Abrir com Sirius" abre uma janela nova a cada arquivo, em vez de usar uma aba da janela que já está aberta.
- GIF animado mostra só o primeiro quadro, e o SVG ainda não tem prévia.
- O Emmet cobre HTML, sem as abreviações de CSS como `m10`.
- Sem depuração dentro da IDE.
- Conflitos de Git são resolvidos editando o arquivo.
- Dentro de `<script>` em arquivos HTML, as sugestões de JavaScript trazem só palavras-chave.
- Arquivos `.sass` não têm sugestões.
- Programas de tela cheia no terminal, como `vim`, não foram testados.
- As atualizações ainda são manuais: a IDE avisa, mas você baixa e instala a versão nova por cima.
