A **Sirius 0.8.0** passa a se atualizar sozinha: quando sair uma versão nova, é só clicar em **Atualizar agora**.

**Ainda em desenvolvimento:** funciona no dia a dia, mas espere arestas. Faça commit do seu trabalho e relate o que encontrar em [Issues](https://github.com/erickfuzer/Sirius/issues).

## Destaques

- **Atualizar pela própria IDE:** o aviso de versão nova, na cápsula, agora oferece **Atualizar agora**. A Sirius baixa o instalador e mostra o andamento no botão. Depois fecha, instala por cima e abre de novo, com suas preferências e abas.
- **Conferência do arquivo:** só é aceito o instalador da página de Releases da Sirius, e só se for exatamente o arquivo que o GitHub registrou para aquela versão, com o mesmo tamanho e a mesma impressão digital (SHA256). Se não bater, nada é instalado.
- **Nada se perde:** antes de fechar, a Sirius faz as mesmas perguntas de quando você fecha a janela, sobre arquivos sem salvar e programa em execução. Cancelar só adia a atualização, e o instalador já baixado fica guardado para a próxima vez.
- **Ver as novidades:** o mesmo aviso ainda abre a página da versão no navegador. Ignorar uma versão passou para a barra de comando.

## Instalação

Esta versão precisa ser instalada do jeito de sempre, uma última vez: as anteriores ainda não sabem se atualizar. Da próxima em diante, basta o botão.

Baixe `Sirius-0.8.0-Setup.exe` abaixo e abra. Se já tem a Sirius, instale por cima: suas preferências continuam. Ele instala só para o seu usuário, sem pedir administrador, e já leva o .NET junto.

O instalador ainda não tem assinatura digital, então o Windows pode mostrar um aviso azul. Clique em **Mais informações** e depois em **Executar assim mesmo**.

Requer Windows 10 versão 1809 ou mais recente, em 64 bits.

## Limites conhecidos

- Sem assinatura digital, a conferência confia no registro do GitHub, como o download manual pela página de Releases.
- Encontrar os usos e formatar dependem do servidor de linguagem do arquivo: em texto puro, a Sirius avisa que não estão disponíveis.
- A depuração é só de PHP e começa pelo botão Executar. Uma página servida por outro programa, como o Apache, não para.
- O terminal repassa a roda do mouse aos programas de tela cheia, mas não os cliques.
- O `vim` e outros programas de tela cheia, além do Claude Code, não foram testados.
- O "Abrir com Sirius" abre uma janela nova a cada arquivo, em vez de usar uma aba da janela que já está aberta.
- GIF animado mostra só o primeiro quadro, e o SVG ainda não tem prévia.
- O Emmet cobre HTML, sem as abreviações de CSS como `m10`.
- Conflitos de Git são resolvidos editando o arquivo.
- Dentro de `<script>` em arquivos HTML, as sugestões de JavaScript trazem só palavras-chave.
